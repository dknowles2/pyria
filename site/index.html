CHILD SAFETY & COMPLIANCE FAQ

Questions From Parents & Educators

Straightforward answers about privacy, COPPA alignment, sandbox security, and classroom or home use.

Does my child need an account or email address to play Pyria?

No. Kids can start playing immediately at play.pyria.dev in Guest Mode without creating an account, entering an email address, or sharing a real name. Progress saves automatically in the browser, and families who want to play across multiple devices (like a laptop and an iPad) can use an anonymous, randomly generated Hero Code or QR code—still with zero personal information required from the child.

How does Pyria handle COPPA and children's privacy compliance?

Pyria follows strict data minimization principles aligned with COPPA (the U.S. Children's Online Privacy Protection Act) and GDPR-K best practices:

  • We do not knowingly collect personal information (real names, email addresses, birthdays, photos, or precise locations) from children under 13.
  • Hero names are fictional in-game character names and are never displayed publicly to other players.
  • We do not run third-party advertising networks, cross-site tracking pixels, or behavioral profiling scripts.
  • Optional Parent Console sign-in (via Google or passwordless Email Magic Link) and optional weekly progress digest emails are intended strictly for parents or adult educators, never children.
Is it safe for my child to run real Python code in the browser?

Yes. Pyria runs Python 3 entirely inside your own browser using Pyodide (WebAssembly)—nothing your child types is ever executed on a remote server. Even better, the Python runtime is isolated inside a dedicated opaque-origin sandboxed iframe with strict Content Security Policy (CSP) headers. Player code cannot read files on your computer, inspect browser cookies, or make unauthorized network requests.

Are there ads, in-app purchases, loot boxes, or external links inside the game?

Never. Pyria has zero advertisements, zero sponsored content, zero microtransactions, and zero pay-to-win mechanics. Every hat, tunic color, boot upgrade, stackable consumable, and custom relic in Bram's Tinkerer Workshop is earned purely through solving Python trials, review challenges, and exploring realms.

Can my child chat with strangers or see user-generated content?

No. Pyria is a 100% single-player adventure RPG. There is no text chat, no voice chat, no friend lists, no public profiles, and no user-generated content shared between players. All dialogue and story cutscenes are curated and family-friendly.

What data is stored, and how can a parent review or delete it?

Only gameplay state is stored—such as the hero's chosen pixel appearance, current realm, Byte Shards, unlocked gear, and Python trial attempts so players don't lose their progress. Parents can review progress or delete any saved hero and its associated attempt history directly from the Saved Heroes screen or Parent Console at any time.

What age range and experience level is Pyria built for?

Pyria is targeted for ages 10 and up—great for kids, teens, and adults alike—and no prior coding experience is needed. Hero Forge lets players pick their starting Python familiarity (brand new, some coding, or comfortable with Python) to automatically calibrate difficulty and hints. Early realms begin with two-step multiple-choice code reading, gentle bug-fixing, and kid-friendly say() / shout() spells before smoothly ramping up to real Python 3 functions, dictionaries, and 3D classes.

What devices does Pyria work on? Does it work on iPad or Chromebooks?

Pyria runs directly in modern web browsers (Chrome, Safari, Firefox, and Edge) on Mac, Windows, Linux, Chromebooks, and iPads / tablets. On touch devices, Pyria includes an on-screen 360° analog thumbstick, tap-to-walk auto-pathing, overworld fast travel, touch-friendly action buttons, and quick-insert Python symbol buttons—and can even be added to the iPad Home Screen like an app.
